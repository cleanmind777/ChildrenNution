# Assets Directory

This directory should contain the following image assets for the app:

## Required Assets

1. **icon.png** (1024x1024)
   - App icon for all platforms
   - Should be square with transparent or solid background

2. **splash.png** (1284x2778 recommended)
   - Splash screen image
   - Shown when app is launching

3. **adaptive-icon.png** (1024x1024)
   - Android adaptive icon foreground
   - Should be centered with padding

4. **favicon.png** (48x48)
   - Web favicon
   - Small icon for web version

## Creating Assets

You can use tools like:
- Figma
- Adobe Illustrator
- Canva
- Online icon generators

## Placeholder Assets

For development, you can create simple placeholder images:
- Solid color backgrounds
- Text-based icons
- Simple logos

## Notes

- All images should be optimized for mobile
- Use PNG format for transparency
- Consider different screen densities
- Test on actual devices
